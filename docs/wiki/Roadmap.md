# План улучшений по результатам проверки кода

Это предложения, а не уже реализованные возможности.

## 1. Корректность

- Проверять допустимость входов сцен, явно отклонять ноль и неподдерживаемые случаи.
- Убрать предположение «остальные биты — нули» после 12 отображаемых разрядов в `BuildDouble`.
- Вычислять нужную длину двоичной записи с учётом нормализации, 52 битов и guard bit.
- Менять пояснение о бесконечной записи для конечных дробей.
- Реализовать специальные кодировки в `decode_fields` либо отклонять E=0 и E=2047.
- Завершать округление переносом из мантиссы в порядок.
- Добавить численные тесты: текущие примеры, ties-to-even в обе стороны, перенос, неверные строки битов, неподдерживаемые значения.

## 2. Сопровождение

- Вынести локализацию в словари с единым кодом сцен.
- Добавить CI для численных тестов и синтаксиса; визуальную проверку рендера проводить отдельно.
- Зафиксировать воспроизводимое окружение и поддерживаемые версии после проверки.

## 3. Учебные материалы

- Добавить отдельный пример точного равенства расстояний: `0.3` его не демонстрирует.
- Подготовить озвучку и субтитры с реальными временными метками.
- Показать два соседних double и понятие ULP.
- При росте бинарных материалов рассмотреть GitHub Releases для готовых видео.
