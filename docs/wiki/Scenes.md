# Сцены

Английские классы `BuildDouble`, `RoundoffError` лежат в `ieee754_scenes.py`, русские `BuildDoubleRU`, `RoundoffErrorRU` - в `ieee754_scenes_ru.py`. Все биты считаются в коде (`struct`, `Fraction`), числа можно менять в начале файла.

## BuildDouble: 19.59375

1. Записать число в двоичном виде по таблице весов: `10011.10011`.
2. Нормализовать: `1.001110011 * 2^4`.
3. Порядок: `4 + 1023 = 1027 = 10000000011`.
4. Мантисса: `001110011` и 43 нуля.
5. Знак: `S = 0`.
6. Подставить S, E, M в формулу и получить `19.59375` (hex `0x4033980000000000`).

## RoundoffError: 0.3

1. Перевод в двоичную запись умножением на 2: остатки повторяются, запись бесконечна.
2. Нормализация: `1.0011001100... * 2^-2`, `E = 1021`.
3. 52 бита попадают в мантиссу, остальное - хвост. Первый отброшенный бит равен 0, поэтому округление идёт вниз.
4. Итог:

```text
хранится = 0.299999999999999988897769753748434595763683319091796875
ошибка   = хранится - 0.3, около -1.1e-17
относительная ошибка около 3.7e-17 (эпсилон 2^-52 около 2.2e-16)
```

Подписи рассчитаны на эти примеры, для других чисел их может понадобиться править.
