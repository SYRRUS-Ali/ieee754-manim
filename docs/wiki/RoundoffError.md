# Погрешность округления: 0.3

Классы: `RoundoffError` (английский), `RoundoffErrorRU` (русский).

Точное число задаётся строкой: `Fraction("0.3") = 3/10`. Хранимое значение получается через `float` и затем `Fraction(float_value)`.

Анимация показывает умножение дроби на два, повторение остатков, запись `0.0100110011…₂`, нормализацию с порядком `−2`, 52 сохраняемых бита и отброшенный хвост.

Для `0.3` остаток после усечения меньше половины единицы последнего сохраняемого разряда, поэтому мантисса не увеличивается. Это не пример точного равенства расстояний, хотя общее правило ties-to-even объясняется в сцене.

```text
S = 0
E = 1021 = 01111111101₂
hex = 0x3FD3333333333333
stored = 0.299999999999999988897769753748434595763683319091796875
stored − exact ≈ −1.1102230246251565 × 10⁻¹⁷
relative error ≈ 3.7007434154171883 × 10⁻¹⁷
```

Отрицательная знаковая погрешность означает, что хранимое число немного меньше `3/10`. Относительная погрешность берётся по модулю. Сцена предполагает положительную периодическую дробь; тексты не универсальны для других входов.
