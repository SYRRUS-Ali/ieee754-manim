# Решение проблем

| Проблема | Действие |
| --- | --- |
| Python открывает Microsoft Store | Использовать полный путь к установленному Python; проверить алиасы запуска приложений. |
| `No module named manim` | Устанавливать и запускать через один `.venv` Python. |
| Запрещена активация PowerShell | Запускать `.venv/Scripts/python.exe` напрямую. |
| Не найдены `latex` / `dvisvgm` | Проверить установку и PATH, открыть новый терминал. |
| Не хватает `.cls` / `.sty` | Установить пакеты из журнала ошибки через менеджер LaTeX. |
| Вместо кириллицы квадраты | Установить DejaVu Sans или выбрать другой кириллический шрифт. |
| Надписи перекрываются | Сократить текст, уменьшить размер или изменить размещение, повторить preview. |
| Нет MP4 в `videos/` | Искать в `media/videos/`; финальные файлы копируются вручную. |
| После замены числа вывод неверен | Проверить ограничения сцен; они не являются универсальным конвертером. |

Для воспроизведения ошибки нужны команда, версии Python/Manim, содержательный фрагмент журнала и проблемный кадр.
