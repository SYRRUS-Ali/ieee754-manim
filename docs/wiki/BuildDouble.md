# Построение double: 19.59375

Классы: `BuildDouble` (английский), `BuildDoubleRU` (русский).

1. Записать число как `10011.10011₂` с помощью весов разрядов.
2. Нормализовать: `1.001110011₂ × 2⁴`.
3. Найти порядок: `4 + 1023 = 1027 = 10000000011₂`.
4. Записать `001110011` и дополнить поле 43 нулями.
5. Установить знак `S=0`.
6. Восстановить число и показать код `0x4033980000000000`.

Ожидаемое точное значение: `627/32 = 19.59375`. Битовая строка вычисляется через `struct`; обратное преобразование проверяется через `Fraction`.

Ограничение: начальная дробная таблица использует максимум восемь битов, таблица мантиссы — двенадцать, после чего остальные разряды объявляются нулями. Для других чисел пояснения могут потребовать исправления.
