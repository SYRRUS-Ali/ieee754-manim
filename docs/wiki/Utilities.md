# Вспомогательные функции

Модуль `ieee754_utils.py` использует стандартную библиотеку, без зависимости от Manim.

| Функция | Назначение и ограничения |
| --- | --- |
| `double_bits` | 64 бита float, старший бит первым; явный big-endian порядок в `struct`. |
| `bits_to_double` | Биты в double; строгой проверки длины и символов нет. |
| `split_fields` | Знак, 11 битов порядка и 52 бита дробной части. |
| `decode_fields` | Точное значение по формуле нормальных чисел. |
| `binary_expansion` | Двоичная запись неотрицательной дроби до заданной длины. |
| `exact_frac_length` | Длина дробной части в пределах лимита; достижение лимита не доказывает завершение записи. |
| `normalize` | Порядок и индекс старшей единицы; нулевая строка не поддерживается. |
| `times_two_steps` | Шаги умножения на два и повторение остатка. |
| `round_mantissa` | Порядок, усечённые биты, остаток и решение об увеличении для положительной дроби; итоговый перенос не реализован. |
| `exact_decimal` | Конечная десятичная запись для знаменателя 2^a × 5^b в пределах точности контекста 2000. |
| `to_decimal`, `sci_tex`, `weight_str` | Форматирование чисел для вывода. |

`Fraction("0.3")` — точный десятичный вход; `Fraction(0.3)` — уже округлённый float.
