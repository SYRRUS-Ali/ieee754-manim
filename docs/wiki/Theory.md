# Теория: double (binary64)

| Поле | Биты | Назначение |
| --- | --- | --- |
| S | 63 | Знак |
| E | 62-52 | Смещённый порядок, 11 бит |
| M | 51-0 | Дробная часть мантиссы, 52 бита |

Для нормального числа (`1 <= E <= 2046`):

`x = (-1)^S * 2^(E-1023) * (1 + M/2^52)`

- Смещение порядка равно 1023: хранится `E = e + 1023`, где `e` - порядок после нормализации.
- Старшая единица нормализованного числа `1.xxxx` не хранится (скрытая единица), поэтому значащих бит 53.
- Дробь имеет конечную двоичную запись, только если её знаменатель - степень двойки. `19.59375 = 627/32` подходит, а `0.3 = 3/10` нет: её запись `0.0100110011...` бесконечна, и всё после 52-го бита мантиссы отбрасывается.
- Округление идёт к ближайшему, при равенстве - к чётному (ties to even).
- Машинный эпсилон `2^-52`, относительная ошибка округления не больше `2^-53`.

Нули, subnormal (`E=0`), бесконечности и NaN (`E=2047`) здесь только упомянуты, сцены их не обрабатывают.
