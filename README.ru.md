## Установка и запуск

Зависимость: `manim==0.22.0`. Нужен совместимый Python; для отдельного окружения можно начать с Python 3.12. Формулы требуют LaTeX и `dvisvgm`. Русские подписи используют DejaVu Sans, биты — DejaVu Sans Mono. В Windows можно установить MiKTeX.

PowerShell из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m manim checkhealth
```

Быстрый просмотр:

```powershell
.\.venv\Scripts\python.exe -m manim -pql ieee754_scenes_ru.py BuildDoubleRU RoundoffErrorRU
```

Финальный рендер 1080p, 60 кадров/с:

```powershell
.\.venv\Scripts\python.exe -m manim -qh ieee754_scenes_ru.py BuildDoubleRU RoundoffErrorRU
```

Стандартный каталог: `media/videos/ieee754_scenes_ru/1080p60/`. После полного просмотра:

```powershell
New-Item -ItemType Directory -Force -Path videos/ru
Copy-Item -LiteralPath media/videos/ieee754_scenes_ru/1080p60/BuildDoubleRU.mp4 -Destination videos/ru/BuildDoubleRU.mp4
Copy-Item -LiteralPath media/videos/ieee754_scenes_ru/1080p60/RoundoffErrorRU.mp4 -Destination videos/ru/RoundoffErrorRU.mp4
```

Для английской версии использовать `ieee754_scenes.py BuildDouble RoundoffError`. Подробнее: [установка Manim](https://docs.manim.community/en/stable/installation/uv.html).

## Теоретическая основа

Binary64: 1 бит знака, 11 битов смещённого порядка, 52 бита дробной части. Для нормального конечного числа:

$$x=(-1)^S\,2^{E-1023}\left(1+\frac{M}{2^{52}}\right).$$

Старшая единица не хранится явно: точность составляет 53 значащих двоичных разряда. В подписях проекта «мантисса» означает хранимую дробную часть.

Первый пример представим точно: `19.59375 = 10011.10011₂ = 1.001110011₂ × 2⁴`. Код: `0x4033980000000000`.

Для `0.3` двоичная запись бесконечна. В double хранится:

```text
0.299999999999999988897769753748434595763683319091796875
```

Код: `0x3FD3333333333333`. Знаковая погрешность примерно `−1.1102230246251565 × 10⁻¹⁷`, относительная — `3.7007434154171883 × 10⁻¹⁷`. Машинный эпсилон `ε = 2⁻⁵²`, единица округления к ближайшему `u = 2⁻⁵³`. Относительная оценка для нормального диапазона не переносится автоматически на subnormal.

## Настройка и ограничения

В начале обоих файлов сцен:

```python
SCENE1_NUMBER = "19.59375"
SCENE2_NUMBER = "0.3"
SCENE2_FRAC_BITS = 90
```

Строки позволяют `Fraction` получить точное исходное десятичное значение. Проект рассчитан на приведённые примеры:

- Первая сцена ограничивает начальную дробную часть восемью битами и таблицу мантиссы двенадцатью, затем предполагает нулевой остаток.
- Вторая сцена предполагает положительную периодическую дробь и достаточное количество битов для округления.
- Общая обработка нуля, отрицательных чисел, subnormal, NaN, бесконечностей и переполнения не реализована.
- `decode_fields` использует формулу нормальных чисел; `round_mantissa` не завершает перенос мантиссы в порядок.
- Русский исходник дублирует структуру английского: алгоритмические изменения нужно вносить согласованно.
- Проверены синтаксис и перевод. Рендер и визуальная проверка русской версии ещё требуются.

Если кириллица отображается квадратами, проверьте шрифт. При ошибках `latex`/`dvisvgm` проверьте установку и PATH. Подробности — в Wiki и английском README.
